# Choosing an Image Format for the Low-Bandwidth Web in 2026

Companion notebook for the paper *Choosing an Image Format for the Low-Bandwidth Web in 2026: An Experimental Comparison of JPEG, WebP, AVIF and JPEG XL on Photographs and Arabic-Text Images*.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Ohidasalsabil/image-formats-low-bandwidth-web/blob/main/image_formats_experiment.ipynb)

One notebook, [`image_formats_experiment.ipynb`](image_formats_experiment.ipynb), produces every table and figure of the paper. It

1. downloads the 24 Kodak photographs and generates 12 synthetic Arabic-text images (768×512 pixels) in code;
2. encodes each image with JPEG, WebP, AVIF (4:2:0 and 4:4:4) and JPEG XL at eight or nine quality settings per format, 1,548 files in total;
3. measures file size (bits per pixel), quality (PSNR-Y, SSIM-Y and SSIMULACRA2), and single-thread encoding and decoding time;
4. computes the Bjøntegaard delta rate (BD-rate) relative to JPEG, the size of a 1920×1080 image at target SSIMULACRA2 scores, and its download time at 1, 2, 5 and 10 Mbit/s;
5. saves all tables (CSV) and figures (PNG) in `results/` and packs them into `results.zip`.

## How to run

1. Click **Open in Colab** above (a Google account is needed).
2. Choose **Runtime → Run all**. The full run takes about 30 minutes on the free tier of Colab.

## Encoders and settings

All codecs are called through the [imagecodecs](https://github.com/cgohlke/imagecodecs) package, version 2026.10.10. Every encoder and decoder runs on a single thread.

| Format | Library | Settings | Quality settings |
| --- | --- | --- | --- |
| JPEG | libjpeg-turbo 3.2.0 | Baseline, optimized Huffman tables, 4:2:0 | 20, 30, …, 90, 95 |
| WebP | libwebp 1.6.0 | Lossy, method 4, 4:2:0 | 20, 30, …, 90, 95 |
| AVIF (4:2:0) | libavif 1.4.2 with the libaom 3.15.1 encoder and the dav1d 1.5.4 decoder | Speed 6, 8-bit, 4:2:0 | 20, 30, …, 90 |
| AVIF (4:4:4) | As above | Speed 6, 8-bit, 4:4:4 | 20, 30, …, 90 |
| JPEG XL | libjxl 0.12.0 | Effort 7, VarDCT in XYB | 20, 30, …, 90, 95 |

**Quality metrics.** PSNR-Y and SSIM-Y are computed on the luma channel, Y = 0.299R + 0.587G + 0.114B; SSIM uses a Gaussian window with σ = 1.5 (scikit-image). SSIMULACRA2 is computed with the official tool from libjxl v0.11.1. For the curves and the BD-rate, SSIM-Y is converted to decibels, −10·log10(1 − SSIM).

**BD-rate.** Computed for each image with PCHIP interpolation of the logarithm of the rate over the common quality range, then averaged over the images (mean and median).

## Reproducibility

The notebook pins imagecodecs 2026.10.10 and Pillow 11.3.0. Pillow draws the Arabic-text images, so its version matters: with Pillow 11.3.0, a run on Google Colab and a second run on another Linux machine gave identical sizes for all 1,548 files, and quality scores that agreed to within floating-point rounding. A different Pillow version renders the glyphs slightly differently and changes the Arabic results. Section 14 of the notebook records the versions used in each run.

## Data

- **Kodak Lossless True Color Image Suite.** The 24 images are downloaded from [r0k.us](http://r0k.us/graphics/kodak/), with a mirror on GitHub as a fallback. They are not redistributed here.
- **Arabic-text images.** Generated by the notebook itself with the Amiri, Noto Naskh Arabic and Cairo fonts from [Google Fonts](https://github.com/google/fonts) (SIL Open Font License). The texts were written for this study.
